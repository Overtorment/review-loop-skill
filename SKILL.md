# /review-loop

review the changes, focus on correctness, performance, robustness. use review skill from superpowers if possible. make sure code is elegant, readable & NOT overengineered. after review is done - validate all findings, and fix the ones that are valid and are worth fixing. keep reviewing & fixing till there are no more issues left (nitpick and minor issues do not count).
WARNING: I request you to do the loop: do review-validate-fix loop until there are no more valid issues left. You must run at least one review iteration with no major findings before stopping the loop
